# My First HTML Website

My first hands-on HTML project, built while learning the fundamentals of web development.

### What I learned

* Structuring a page with semantic HTML5 elements such as `header`, `nav`, `main`, `article`, `section`, `aside`, and `footer`
* Working with headings, paragraphs, links, images, lists, and semantic text elements
* Creating accessible navigation and using attributes such as `alt`, `aria-label`, and `scope`
* Building tables with `thead`, `tbody`, `tfoot`, `rowspan`, and `colspan`
* Creating forms with different input types, labels, validation rules, radio buttons, checkboxes, `datalist`, `textarea`, and buttons
* Using `figure`, `figcaption`, `time`, `address`, `details`, and other semantic elements
* Understanding basic accessibility and meaningful HTML structure
* Linking HTML pages, CSS files, images, and external resources
* Using GitHub to document and track my learning

This is a beginner project, but it was the first step from *reading about web development* to actually building something with it.
